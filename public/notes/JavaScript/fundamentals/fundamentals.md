## Valores

Los valores representan los datos reales que una computadora manipula, almacena y procesa. Estos valores pueden ser números, fragmentos de textos, funciones, etc.

### Valores primitivos

Los valores primitivos son los tipos de datos más báscios y fundamentales que representan un único valor. No son estructuras complejas y son la base sobre la cual se construye la lógica del lenguaje. Entre los principales tenemos:

* Number
* String
* Boolean
* BigInt
* Symbol
* undefined
* null

### Valores por referencia

Son __estructuras complejas__ que permiten almacenar colecciones de valores o funcionalidades. Estas estructuras almacenan referencia a espacios de memoria donde se guardan los valores o funcionalidades de cada colección. Entre los principales tenemos:

* Object
* Array
* Function
