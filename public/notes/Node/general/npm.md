## NPM

NPM (Node Package Manager) es un administrador de paquetes para JavaScript que permite a los desarrolladores instalar, compartir y gestionar código reutilizable (paquetes o librerías).

## Timers

* **setInterval**: Ejecuta codigo cada cierto tiempo.

```javascript
setInterval(() => {
  console.log('Hello world')
}, 1000)
```

* **settimeout**: Ejecuta codigo después de cierto tiempo.

```javascript
setTimeout(() => {
  console.log('Hello world')
}, 5000)
```
