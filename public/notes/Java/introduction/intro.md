## ¿Que es?
Es un lenguaje de programación **multiplataforma**, **orientado a objetos** y una **plataforma de computación**.

Permite construir aplicaciones que corran en diferentes sistemas operativos y arquitecturas. Para esto se usa el JVM (Java Virtual Machine).

El procesos es: `Java` -> `Java compiler` -> `Java byte code` -> `JVM`

> *JVM* se encarga de proporcionar una especificación de como de debe ejecutar el código dependiendo de la arquitectura y sistema operativo.

Para usar JVM necesitamos un ambiente para correr java (JRE -> Java Runtime Environment).

Para compilar el código debemos usar un JDK (Java Development Kit) el cual incluye un compilador y al mismo tiempo el JRE. Al final de cuentas es el que necesitamos.

## Orientado a objetos
Java es un lenguaje orientado a objetos, por lo cual es indispensable que sepamos **Programación Orientada a Objetos** (POO). En otras secciones veremos lso conceptos relacionados a POO.

Por ahora debemos saber que Java debe tener una **clase principal** llamada `Main` y debe tener una función o método `main()`. Este método será el primero que se ejecute en nuestra aplicación.
